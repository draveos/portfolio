# 쿼리도 대국 판 (사람 대 에이전트)

브라우저 안에서 쿼리도를 탐색 에이전트와 두는 정적 데모입니다. 서버, 빌드, 외부 라이브러리 없이 이 폴더의 파일만으로 동작합니다.

## 이식 출처

- 상대 에이전트(`agent.js`)는 quoridor-arena 프로젝트의 `engine/agents/codex.py`(563줄)를 JS 로 옮긴 것입니다. codex.py 는 GPT 가 작성한 에이전트이며, 비교 실험(리그 42개, 20판 프로토콜)에서 사람이 쓴 에이전트와 사무실 회의가 만든 office 계열보다 강했습니다. 제가 설계한 에이전트가 아니라 "가장 강했던 상대"를 그대로 옮긴 것입니다.
- 규칙 엔진(`rules.js`)은 pip 패키지 pyquoridor 0.0.5 의 판정(이동, 점프, 대각 점프, 울타리 겹침, 경로 차단)과 codex.py 의 울타리 기하(21~48행, 105~123행)를 옮겼습니다.
- 알고리즘 구조는 원본과 같습니다. 81칸 벽 그래프 위 반복심화 negamax 알파베타(깊이 1~8), 치환표, 벽 배치별 토폴로지 캐시, 보호 경로 평가, 함정 예측과 방어벽 보존, 48국면 반복 무승부 처리, 상대 벽이 0장일 때 정확 역행 분석.
- 규칙 판정 일부는 pyquoridor 0.0.5(MIT, Ramon Viñas Torné)를 참고했습니다. 라이선스 전문은 `LICENSE-pyquoridor.txt` 입니다.
- 달라진 점: 128비트 마스크를 32비트 워드 4개와 BigInt 로 나눠 들고, 치환표 키를 토폴로지 id 로 만듭니다. 시간 예약은 Python 의 25%(최대 0.30초) 대신 15%(최소 12ms)이고, 시간 확인은 32노드가 아니라 16노드마다 합니다. 인접 그래프는 칸당 4칸짜리 Uint8Array 로 들어 토폴로지 캐시를 가볍게 했습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 판, 점수판, 상태 문구, 버튼. iframe 안에서 단독 동작 |
| `rules.js` | 이동, 점프, 울타리 합법성, 승리 판정. `globalThis.QRules` |
| `agent.js` | codex.py 이식. Web Worker 로 실행되며 Worker 생성에 실패하면 메인 스레드에서 돕니다. `globalThis.QAgent` |
| `ui.js` | 9×9 SVG 판, 클릭과 터치 입력, 벽 놓기 모드, 키보드 접근, 부모 페이지 계약 |
| `style.css` | 블로그 토큰(`--ink`, `--muted`, `--line`, `--blue`)과 Pretendard 글꼴(`../../fonts/`) |

## 조작

- 사람은 아래에서 시작합니다. 밝게 표시된 칸을 누르면 이동합니다(점프, 대각 점프 포함).
- 벽 놓기: `벽 놓기` 버튼 또는 `F`. 가로와 세로는 `가로/세로` 버튼 또는 `R`. `Esc` 로 이동 모드로 돌아갑니다.
- 마우스는 자리 위에서 미리보기(초록 합법, 빨강 불법)가 보이고 클릭하면 놓습니다. 터치는 첫 번째 누름이 미리보기, 같은 자리 두 번째 누름이 설치입니다.
- 키보드만으로도 둘 수 있습니다. 이동 후보 칸과 64개 벽 자리가 Tab 순서에 들어가고 Enter 또는 Space 로 선택합니다.
- 되돌리기는 없습니다. 300수가 지나면 무승부입니다(아레나 서버 규칙).
- 선공은 `선공` 선택과 `다시 시작`으로 바꿉니다. 에이전트가 선공이어도 사람은 아래에서 시작합니다.

## 시간 예산

수당 데스크톱 400ms, 모바일(`pointer: coarse` 또는 논리 코어 4개 이하) 600ms 입니다. 이 맥(2026-10-14 실측, 기보에서 뽑은 국면 15개)에서 400ms 는 완료 깊이 중앙값 5(최소 3, 최대 8), 노드 중앙값 10,501, 소요 최대 340ms 였습니다. 600ms 는 깊이 중앙값 5, 노드 중앙값 14,341, 소요 최대 514ms 입니다. 모바일 실기기는 재지 못했습니다. 응답이 250ms 보다 빠르면 250ms 까지 기다렸다가 둡니다.

## 블로그에 넣기

글 본문에서 `demoBlock({ src: 'demo/quoridor/index.html', poster: ..., title: '쿼리도 대국', height: 600 })` 처럼 넣습니다. 세로로 쌓이는 390px 폭에서는 약 560px, 두 열이 되는 640px 이상에서는 약 480px 이 필요하므로 `height` 는 600 정도가 안전합니다. 부모가 보내는 `postMessage({type:'portfolio:visible', visible:false})` 를 받으면 진행 중인 탐색은 끝까지 두되 새 탐색은 시작하지 않고, 다시 `visible:true` 가 오면 미뤄 둔 차례를 둡니다.

## 검증

`work/quoridor_port_test.mjs` 로 확인했습니다(결과는 `work/quoridor_port_report.md`).

1. pyquoridor `tests.py` 의 테스트 8개를 1:1 로 옮겨 단언 86개 통과.
2. quoridor-arena 의 `data/codex-qa/matches-*.json` 기보 319판 13,278수를 재생해 모든 수가 합법이고 최종 상태와 승자가 일치.
3. 같은 국면 15개에 노드 예산(300, 1,500, 5,000)을 주고 Python codex.py 와 비교해 45개 모두 같은 수를 골랐고 노드 수와 완료 깊이도 같았습니다.
4. 에이전트 대 greedy 10판 자동 대국(선후공 교대, 수당 400ms).
